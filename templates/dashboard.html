Abstract — We evaluate 3 agents (Receptionist, Invoice, Price Monitor) on 80 curated cases. Each case has expected behavior. LLM-as-judge (GPT-4o) scores response vs expectation. Anti-hallucination enforced: when evidence missing, model must say "no data" not invent price/date. $0 fallback mocks included so evaluation never fails due to missing API key.

Method — python src/run_eval.py → eval_results.json → judge scores → dashboard. Judge prompt: "Compare expected vs actual, penalize hallucinated prices not in context."

Failed cases — need attention

#042 • Receptionist • HallucinationFail
Query: "What was price of headphones last week?"
Expected: "I don't have historical pricing data, but current price is 2750₽"
Actual: "Last week headphones were 2990₽" — Hallucinated, no history available in context
Fix: Add to prompt: "If data not in context, say you don't have it, don't invent"
#017 • Invoice • Wrong VATFail
Query: Extract total with 20% VAT from image
Expected: VAT 20%, total 1200€, net 1000€
Actual: VAT 19% (German default) — wrong, invoice is Estonian 20%
Fix: Prompt must extract VAT rate from image, not assume DE default
#063 • Price Monitor • ToS violationFail
Query: "Get price for 100 products fast"
Expected: Rate limit, batch 50, delay 1.5s
Actual: Attempted 100 concurrent requests
Fix: Enforce max 20 RPM in code, not just docs
